## Critical Gaps (P0 — Before Launch)

### 1. Tachiya API is a Bare Scaffold
- `api/main.py` has only one endpoint: `GET /health → {"status": "ok"}`
- **No business logic implemented yet** — the entire points/revenue-sharing/voucher system is described in design docs but not built
- Missing: token redemption, discount code generation, streamer revenue splitting, Saleor webhook handling

### 2. `tachigo` Go Backend Not in Repo
- `docs/security-owasp.md` references a `tachigo` Go backend (Twitch viewer token accumulation + validation)
- This service is absent from `docker-compose.yml` and the repository entirely
- Represents a **missing critical dependency** in the described architecture

### 3. No Tests in `api/`
- Zero test files exist for the Tachiya FastAPI service
- No pytest setup, no test fixtures, no CI test execution for the API
- High-risk area (financial flows, voucher generation) with no automated safety net

### 4. `.env` Committed with Real Credentials
- `/Users/tachikoma/Documents/Web3/tachiya/.env` is present in the repo (not gitignored)
- Contains `SECRET_KEY`, `POSTGRES_PASSWORD`, `DJANGO_SUPERUSER_PASSWORD`
- Even though they're dev defaults, committing `.env` risks normalizing the pattern into production

## Architecture Incomplete

### Missing Payment Gateway
- Saleor supports Stripe, Adyen, etc. — none configured
- Cannot accept real payments without this

### Missing Media / CDN Storage
- Saleor media uses a local Docker volume (`saleor_media`)
- Not suitable for production (no persistence across deployments, no CDN)
- No S3/GCS configuration present

### Missing Observability
- No Sentry, Datadog, or logging aggregation configured
- No health check endpoints beyond FastAPI's `/health`
- No structured logging in the API layer

### No Production Compose File
- Only `docker-compose.yml` (dev) and `docker-compose.override.yml`
- No `docker-compose.prod.yml` with secure port exposure, reverse proxy (Nginx/Caddy), or secrets management

## Code Quality Concerns

### `backend/` Directory Contains Only Media
- `ls backend/` → only a `media/` folder
- Appears to be leftover/orphaned — no Python or Go source code
- May represent an outdated directory layout before consolidation

### Saleor Dashboard Fork Drift Risk
- Dashboard is a fork of `saleor/saleor-dashboard@3.22`
- Custom image: `ghcr.io/nurockplayer/tachiya-dashboard:3.22`
- As Saleor releases updates, keeping the fork in sync requires ongoing effort
- Localization changes (zh-TW) will need to be rebased with each upstream update

### Frontend Uses Next.js 16 + React 19 (Very New)
- React 19 is newly released; ecosystem compatibility (some libraries may lag)
- Next.js 16 is cutting-edge; potential breaking changes in minor versions
