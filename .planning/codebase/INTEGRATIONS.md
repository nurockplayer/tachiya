## External Service Dependencies

### Saleor Platform
- **Version:** 3.22
- **Image:** `ghcr.io/saleor/saleor:3.22`
- **Role:** Core e-commerce backend (products, orders, checkout, payments, users)
- **Interface:** GraphQL API at `http://localhost:8000/graphql/`
- **Tachiya API calls Saleor via:** httpx (REST/GraphQL client)

### PostgreSQL 16
- **Image:** `postgres:16`
- **Shared by:** Saleor (Django ORM) — Tachiya API likely shares same DB
- **Env vars:** `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD`, `DATABASE_URL`

### Valkey / Redis
- **Image:** `valkey/valkey:8.1-alpine`
- **Used for:**
  - Django cache (`CACHE_URL` → redis://cache:6379/0)
  - Celery broker (`CELERY_BROKER_URL` → redis://cache:6379/1)
  - Celery result backend (`CELERY_RESULT_BACKEND` → redis://cache:6379/2)

### Mailpit (Dev SMTP)
- **Image:** `axllent/mailpit`
- **Ports:** SMTP 1025, Web UI 8025
- **Purpose:** Captures all outgoing email in dev; replace with real SMTP in prod
- **Env:** `EMAIL_URL=smtp://mailpit:1025`
